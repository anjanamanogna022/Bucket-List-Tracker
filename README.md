# BucketList Tracker

A simple and interactive web app to help you track and manage your bucket list items. Add, edit, mark as complete, and remove items as you work toward your life goals!

---

## Features

1. Add new bucket list items  
2. Edit existing items  
3. Mark items as completed  
4. Delete items you no longer needed  
5. Clean and user-friendly interface

---

## Tech Stack

- HTML  
- CSS  
- JavaScript
